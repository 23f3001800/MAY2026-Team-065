# API Test Cases

This directory contains manual API test cases for Smart CivicConnect.

## Contents

- API_Test_Cases.xlsx

The spreadsheet includes:

- Test Case ID
- API Endpoint
- HTTP Method
- Test Scenario
- Request Input
- Expected Output
- Actual Output
- Test Result
- Remarks

The test cases are maintained and updated whenever new APIs are added or existing functionality changes.

These test cases were prepared as part of Sprint 1 QA activities.
